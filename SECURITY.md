# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please report it
privately so it can be addressed before public disclosure.

**Do not open a public GitHub issue for security problems.**

Email the maintainer directly, or use GitHub's private vulnerability reporting
(https://github.com/SoftLand-Tech/laravel-theme-builder/security/advisories).

Please include:

- The package version affected.
- A description of the vulnerability and its impact.
- Reproduction steps or a proof of concept (if available).
- Any suggested remediation.

You should receive a response acknowledging the report. If you do not hear back
within 72 hours, follow up on the same channel.

## Scope

This policy covers the `softlandtech/theme-builder` package, including its
Blade views, controllers, and the React editor under `resources/js`.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |
| < 0.1   | No        |
